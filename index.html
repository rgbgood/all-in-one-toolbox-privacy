🔒 隐私政策

多合一工具箱（All-in-One Toolbox）· 最后更新：2025年1月
核心承诺：本扩展不收集、不上传、不共享任何用户数据。所有数据仅保存在您的本地浏览器中。

1. 简介

本隐私政策适用于 Chrome 浏览器扩展程序「多合一工具箱」（以下简称"本扩展"）。本扩展是一款提供表单快速填写、URL 关键词提取、批量 URL 工具的效率插件。

我们极其重视用户隐私。本政策将详细说明本扩展如何处理（或更准确地说，不处理）您的数据。

2. 我们收集哪些数据？

答案：我们不收集任何数据。

本扩展不会收集、记录、上传或传输以下任何信息：

  • ❌ 您的浏览历史或访问的网站
  • ❌ 您填写的表单内容
  • ❌ 您提取的 URL 或页面内容
  • ❌ 您的 IP 地址、设备信息、操作系统
  • ❌ 您的个人身份信息（姓名、邮箱、电话等）
  • ❌ 任何使用统计数据或分析数据

3. 本地存储的数据

本扩展使用 Chrome 提供的 chrome.storage.local API，在您的本地浏览器中保存以下配置数据，以便您下次使用时能够继续使用：

数据类型 用途 存储位置
表单填写模板 保存您配置的字段定位器和填写内容 本地浏览器
常用模板列表 记录您标记为常用的模板 本地浏览器
URL 匹配规则 保存自动填写触发规则 本地浏览器
保护密码哈希 用于验证身份（SHA-256 加盐哈希，不可逆） 本地浏览器
界面语言偏好 记住您选择的界面语言 本地浏览器

重要说明：以上所有数据仅存储在您的本地浏览器中，本扩展不会将其上传到任何远程服务器，也不会与任何第三方共享。您可以随时通过卸载扩展来清除全部数据。

4. 权限用途说明

本扩展申请以下权限，均仅用于实现对应功能，不用于其他目的：

权限 用途
activeTab 在用户主动点击按钮时，访问当前标签页以执行表单填写或 URL 提取
storage 在本地保存您的模板和偏好设置
scripting 向用户当前页面注入脚本，执行填写和提取操作
tabs 获取标签页信息以支持批量打开和批量复制
webNavigation 监听页面导航，触发自动填写
clipboardWrite 将提取的 URL 复制到剪贴板
contextMenus 添加右键菜单以复制选定链接
<all_urls> 允许用户在任意网站上使用本扩展的功能（用户主动触发）

5. 第三方服务

本扩展不使用任何第三方分析、广告、跟踪服务。本扩展不包含任何远程代码或外部资源。

6. 儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

7. 政策更新

如本政策发生重大变更，我们将在本页面更新并修改"最后更新"日期。建议您定期查看本页面。

8. 联系方式

如您对本隐私政策有任何疑问或建议，请通过 Chrome 应用商城的反馈渠道联系我们。

🔒 Privacy Policy

All-in-One Toolbox · Last Updated: January 2025
Core Commitment: This extension does not collect, upload, or share any user data. All data is stored locally in your browser.

1. Introduction

This Privacy Policy applies to the Chrome browser extension "All-in-One Toolbox" (the "Extension"). The Extension is a productivity tool providing quick form filling, URL keyword extraction, and batch URL utilities.

We take your privacy very seriously. This policy explains in detail how the Extension handles (or more accurately, does not handle) your data.

2. What Data Do We Collect?

Answer: We collect no data whatsoever.

The Extension does NOT collect, record, upload, or transmit any of the following:

  • ❌ Your browsing history or visited websites
  • ❌ Form data you fill in
  • ❌ URLs you extract or page content
  • ❌ Your IP address, device info, or operating system
  • ❌ Your personal identity information (name, email, phone, etc.)
  • ❌ Any usage statistics or analytics

3. Locally Stored Data

The Extension uses Chrome's chrome.storage.local API to save the following configuration data locally in your browser, so you can continue using it next time:

Data Type Purpose Storage Location
Form fill templates Store your configured field locators and values Local browser
Favorite templates Record templates you marked as favorites Local browser
URL match rules Save auto-fill trigger rules Local browser
Password hash Identity verification (SHA-256 salted hash, irreversible) Local browser
Language preference Remember your chosen UI language Local browser

Important: All of the above data is stored only in your local browser. The Extension does not upload it to any remote server, nor does it share it with any third party. You can clear all data at any time by uninstalling the Extension.

4. Permissions Explained

The Extension requests the following permissions, all used solely for their corresponding features:

Permission Purpose
activeTab Access the current tab when the user clicks a button, to fill forms or extract URLs
storage Save your templates and preferences locally
scripting Inject scripts into the current page to fill and extract
tabs Get tab info to support batch open and batch copy
webNavigation Listen to page navigation to trigger auto-fill
clipboardWrite Copy extracted URLs to clipboard
contextMenus Add a right-click menu to copy selected links
<all_urls> Allow users to use the Extension on any website (triggered by user action)

5. Third-Party Services

The Extension does not use any third-party analytics, advertising, or tracking services. It does not contain any remote code or external resources.

6. Children's Privacy

The Extension is not intended for children under 13 and does not knowingly collect personal information from children.

7. Policy Updates

If this policy changes materially, we will update this page and revise the "Last Updated" date. We recommend checking this page periodically.

8. Contact

If you have any questions or suggestions about this Privacy Policy, please contact us through the Chrome Web Store feedback channel.
